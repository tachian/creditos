# Expectativas de Consumidores

Consumidores podem adicionar expectativas e testes de compatibilidade neste
espaço, preferencialmente em diretórios por consumidor e contrato.

Exemplo futuro:

```text
consumer-expectations/
  decision-service/
    proposal-submitted/v1/
      README.md
      expected-fields.json
```

Esta story cria apenas o ponto de extensão; testes de consumidores concretos
serão adicionados quando os contratos reais forem materializados.
